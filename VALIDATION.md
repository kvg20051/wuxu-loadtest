# Проверка пакета

Дата: 16 ноября 2026 года.

- Python 3.12.14, Windows x86-64, HTTPX 0.28.1.
- 21 автоматический тест: все прошли.
- Проверены: SSE, Unicode, multiline SSE, HTTP 200 с ошибкой внутри потока, обрыв потока,
  полный таймаут запроса, HTTP 429, Retry-After, отсутствие usage, пустой ответ, JSON-режим,
  проверка моделей, остановка по 401/403 и серии ошибок, остановка оператором,
  дедупликация ключей, параметры, перцентили и экранирование формул в CSV.
- Проверен реальный запуск CLI через HTTPX против локального HTTP/SSE-сервера:
  30 виртуальных пользователей, пик 30 одновременных запросов, 60 успешных запросов нагрузки
  и 1 отдельный пробный POST, 0 ошибок. Сработал установленный предел 61 POST.
- В проверке были многотуровые диалоги; сформированы CSV, JSONL, JSON и Markdown.
  Тестовый секрет не найден ни в одном файле отчёта.
- Сетевые запросы проверки выполнялись только к localhost. WUXU, LiteLLM и внешние LLM
  в проверке не использовались; реальные API-ключи не предоставлялись.
- Bash-обёртка не запускалась: Bash отсутствует в среде проверки. Запуск на Ubuntu и
  совместимость параметров с конкретной боевой моделью нужно проверить через `bash run.sh --smoke`.

Повторить модульные проверки после установки зависимостей:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Это функциональная проверка генератора, а не результат нагрузочного тестирования WUXU.
